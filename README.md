# Kaan Berk Can — Game & System Design Portfolio

Personal portfolio website built from [Notion portfolio content](https://cerulean-act-73f.notion.site/Kaan-Berk-Can-Game-System-Design-Portfolio-3256b68064b8803e9a43e00ca6ee9454).

## Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS 4

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Deploy

Deploy to [Vercel](https://vercel.com), Netlify, or any static/Node host that supports Next.js.
